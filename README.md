# 合成世一班

一个致敬「合成大西瓜」的网页小游戏：两颗同级小球碰撞后合成下一级，从「牢」一路合成为 ZT。

## 合成路线

`牢 → C → 振 → 只 → 米 → 蛋 → AJYC → ZT → 2班`

## 玩法

- 触摸 / 鼠标：按住并拖动瞄准，松手后投放小球。
- 提供「流畅 / 标准 / 精细」三档画面质量，设置会保存在浏览器本地。
- 键盘玩家可用 `←` / `→` 微调，`↓` 或空格投放。
- 只会随机刷新前四个小球：`牢`、`C`、`振`、`只`，且小球出现概率更高。
- 两颗完全相同的小球碰撞会合成更高等级。
- 堆到红色危险线并保持一段时间后游戏结束；本版下落更快、投放间隔更短、判定更快。
- 分数和最高分会自动保存在浏览器本地。

## 运行

直接用浏览器打开 `index.html`，或使用任意静态文件服务器运行本项目。

## 说明

- 画面采用彻底的二维二次元风格；`AJYC`、`ZT` 与 `2班` 使用自定义圆形图片。
- 合成 `ZT` 时显示「母校建校20周年快乐」并燃放二维烟花；合成 `2班` 时显示「永远的高2023级2班」约 5 秒。小球碰撞按三维球体质量 \(m\propto r^3\) 计算动量守恒，并使用较低恢复系数降低弹起高度。
- 地面水平摩擦更低，较大球合成时拥有更强的二维动漫爆发特效。

本项目是纯 HTML / CSS / JavaScript 实现，没有第三方运行时依赖。

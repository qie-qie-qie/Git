# 合成世一师

一个致敬「合成大西瓜」的网页小游戏：两颗同级小球碰撞后合成下一级，从「牢」一路合成为 ZT。

## 合成路线

`牢 → C → 振 → 只 → 米 → 蛋 → AJYC → ZT`

## 玩法

- 鼠标 / 触摸移动瞄准，点击或按空格投放小球。
- 键盘玩家可用 `←` / `→` 微调，`↓` 或空格投放。
- 两颗完全相同的小球碰撞会合成更高等级。
- 堆到红色危险线并保持一段时间后游戏结束。
- 分数和最高分会自动保存在浏览器本地。

## 运行

直接用浏览器打开 `index.html`，或使用任意静态文件服务器运行本项目。

## 说明

本项目是纯 HTML / CSS / JavaScript 实现，没有第三方运行时依赖。
